## 💻 What I Do

### 🐍 Python & Django Development
I build backend systems using the Python ecosystem, with Django as one of my primary frameworks.

Areas I work with include:
* Django & Django REST Framework
* REST API development & Backend architecture
* Database-driven applications & Authentication/Authorization
* Business logic, Validation systems & Testing
* Production issue resolution & Background processing/automation

I particularly enjoy working on systems where backend logic, automation, and AI need to work together reliably.

---

### 🤖 AI & Machine Learning
AI is one of the main areas I'm actively exploring and building with.

My interests include:
* Artificial Intelligence & Machine Learning
* Generative AI & Large Language Models (LLMs)
* AI-powered applications & Computer Vision
* AI automation & Intelligent document processing
* AI-assisted workflows & Data-driven decision systems

Rather than treating AI as a separate experiment, I’m interested in **embedding AI directly into useful software products**.

---

### 📊 Data Science
My background and interests also extend into **data science and machine learning**.

I enjoy working with:
* Data analysis & Data processing
* Feature engineering & ML workflows
* Model experimentation & Python-based data tooling
* Data visualization & Intelligent data-driven applications

My goal is to connect data science with real-world software rather than keeping models isolated from production systems.

---

### ⚙️ Production Engineering & Deployment
I also work on the less glamorous — but extremely important — side of software development: **making applications actually work in production.**

That includes:
* Production deployments & Dependency management
* Linux environments & Docker containerization
* Railway deployments & Build configuration
* Runtime debugging & CI/CD workflows
* Environment configuration & Production testing

I’m particularly interested in understanding what happens **after the code leaves the local development environment**.

---

### 🚀 Real-World Product Development
I’m not only interested in tutorials or isolated experiments. I work on real applications that need to survive **actual production environments**.

One example is my work around **Zlaqa**, where I’ve worked on backend functionality, deployment, testing, and production fixes.

This type of work has involved moving through the complete lifecycle:

```text
Idea → Development → Testing → Bug Fixing → Deployment → Production → Monitoring → Continuous Improvement
```
